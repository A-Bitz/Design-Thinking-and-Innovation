## 1. What is Ideation?

**Ideation** is the creative process of generating, developing and communicating a large number of new ideas in response to a clearly defined problem (a "How Might We" question).

```
Empathize → Define → [ IDEATE ] → Prototype → Test
```

> "The best way to have a good idea is to have lots of ideas." — Linus Pauling

**Ideation aims to:**

- move from the *problem space* to the *solution space*;
- go beyond the first, obvious solution;
- use the whole team's perspectives;
- uncover unexpected areas of innovation;
- build a pool of options to prototype.

---

## 2. Ground Rules for Ideation

These rules were popularised by IDEO and the Stanford d.school:

| Rule | What it means |
|---|---|
| **Defer judgement** | No criticism while generating; evaluate later. |
| **Go for quantity** | Aim for 50–100 ideas. Quality comes from volume. |
| **Build on others' ideas** | Say "Yes, and…" instead of "No, but…". |
| **Encourage wild ideas** | Crazy ideas often lead to practical breakthroughs. |
| **Stay focused** | Keep the HMW question visible. |
| **Be visual** | Sketch, use sticky notes, one idea per note. |

## 3. The Ideation Funnel

```
  GENERATE   ████████████████████  100+ raw ideas      ← DIVERGENT
  CLUSTER     ██████████████       group into themes
  EVALUATE      ████████           assess vs criteria   ← CONVERGENT
  SELECT          ███              2–3 ideas to prototype
```

**Diverge** to create choices, then **converge** to make choices.

## 4. Creativity Techniques

| Technique | How it works | Best for |
|---|---|---|
| **Brainstorming** | Group generates ideas freely, following the ground rules | Quick volume |
| **Brainwriting (6-3-5)** | 6 people write 3 ideas in 5 minutes, then pass sheets on | Including quiet voices |
| **Mind mapping** | Radial map of ideas branching from a central theme | Exploring a topic |
| **SCAMPER** | 7 prompts to modify an existing product or process | Improving what exists |
| **Crazy 8s** | Sketch 8 different ideas in 8 minutes | Visual concepts |
| **Worst Possible Idea** | Generate terrible ideas, then reverse them | Breaking creative blocks |
| **Role playing** | Act out user scenarios | Services and experiences |

### 4.1 Mind Mapping (Tony Buzan)

**Steps:**

1. Write the central problem in the middle of the page.
2. Draw main branches for key themes.
3. Add sub-branches with **keywords**, not sentences.
4. Use colours, images and symbols.
5. Look for connections across branches.
6. Circle promising ideas.

**Example: "How might we reduce food waste in the college canteen?"**

```
                          ┌─ Portion sizes too large
              Students ───┼─ Skip meals after pre-ordering
                 │        └─ Unaware of waste impact
                 │
                 │        ┌─ Over-preparation
   Kitchen ──── [ FOOD WASTE ] ──── Technology ──┬─ Pre-order app with cut-off
      │                  │                      ├─ Waste-tracking dashboard
      ├─ No demand forecast                     └─ Menu voting
      └─ Short shelf-life items
                         │
                     Community ──┬─ Donate surplus to NGOs
                                 ├─ Compost for campus garden
                                 └─ Waste-free week challenge
```

💡 **Cross-branch combination:** pre-order app + surplus donation alerts.

### 4.2 SCAMPER (Bob Eberle, based on Alex Osborn)

| Letter | Prompt | Question to ask |
|---|---|---|
| **S** | Substitute | What can be replaced: materials, people, steps? |
| **C** | Combine | What ideas or features can be merged? |
| **A** | Adapt | What can we borrow from another context? |
| **M** | Modify | What can be enlarged, shrunk or reshaped? |
| **P** | Put to other use | Can it serve another purpose or user? |
| **E** | Eliminate | What can be removed or simplified? |
| **R** | Reverse / Rearrange | What if we changed the order or flipped it? |

**Applied example: redesigning the college library**

| | Idea |
|---|---|
| **S** | Replace the issue desk with self-checkout kiosks |
| **C** | Combine the library with a café and group-study pods |
| **A** | Adapt Netflix-style recommendations for books |
| **M** | Extend hours during exam weeks; create bigger quiet zones |
| **P** | Use the library as a weekend maker-space |
| **E** | Remove late fines; send reminders instead |
| **R** | Deliver books to classrooms instead of students coming in |

### 4.3 Idea Generation in Practice

- **How Might We:** reframe insights as questions (e.g., *HMW make queuing enjoyable?*).
- **Brainwriting 6-3-5:** 6 people × 3 ideas × 6 rounds = **108 ideas in 30 minutes**.
- **Crazy 8s:** fold an A4 sheet into 8 panels, one sketch per minute, then share and dot-vote.
- **Worst Possible Idea:** list the worst solutions, then flip each into its opposite.

### 4.4 Role Playing

Team members act out a real scenario as users, staff or stakeholders. Acting reveals pain points, emotions and moments that interviews miss.

1. **Pick a scenario** (e.g., a first-year student finding a classroom).
2. **Assign roles**: user, staff, observer, note-taker.
3. **Act it out** for 5–10 minutes.
4. **Debrief**: What frustrated? What delighted?
5. **Ideate**: turn each pain point into an HMW.

## 6. Prioritization: From Many Ideas to the Few Worth Building

**Why prioritise?**

- Time, money and people are limited.
- It focuses effort on high-value ideas.
- It gives an objective basis for decisions and avoids the **HiPPO** (Highest Paid Person's Opinion).

| Technique | Description |
|---|---|
| **Impact vs Feasibility Matrix** | Plot ideas on a 2×2 grid |
| **Weighted Scoring** | Score ideas on weighted criteria |
| **Dot Voting** | Each member places 3–5 dots on favourite ideas |
| **MoSCoW** | Must have, Should have, Could have, Won't have |
| **NUF Test** | Rate each idea on New, Useful, Feasible (1–10) |
| **Four Categories** | Most rational, most delightful, darling, long shot |

### 6.1 Impact vs Feasibility Matrix

```
        HIGH │   BIG BETS        │   QUICK WINS ⭐
             │ High impact,      │ High impact,
   IMPACT    │ hard to do        │ easy to do → Do first!
             ├───────────────────┼───────────────────
             │   MONEY PIT ❌    │   FILL-INS
        LOW  │ Low impact,       │ Low impact,
             │ hard → Avoid      │ easy → If time permits
             └───────────────────┴───────────────────
                 LOW        FEASIBILITY        HIGH
```

**How to use it:**

1. Define what "impact" means (user value, reach, goals).
2. Define "feasibility" (cost, time, skills, technology).
3. Place each idea on the grid as a team.
4. Discuss disagreements: they reveal hidden assumptions.
5. Pick 1–2 quick wins and 1 big bet to prototype.

### 6.2 Weighted Scoring

**Example: HMW reduce canteen queue time? (scores 1–5)**

| Criterion | Weight | Pre-order app | Extra counter | Token display |
|---|---|---|---|---|
| User impact | 40% | 5 | 3 | 4 |
| Feasibility | 30% | 3 | 5 | 4 |
| Cost | 20% | 3 | 2 | 4 |
| Time to build | 10% | 3 | 4 | 4 |
| **Weighted total** | **100%** | **3.8** | **3.5** | **4.0** ✅ |

**Formula:** Total = Σ (score × weight)
Token display = 4(0.4) + 4(0.3) + 4(0.2) + 4(0.1) = **4.0**

**Steps:** list criteria → assign weights (sum = 100%) → score each idea → multiply and add → rank.

## 7. Time Management in Design Thinking

Creativity thrives under healthy constraints.

| Technique | Idea |
|---|---|
| **Timeboxing** | Fix a duration for each activity; stop when time is up. |
| **Parkinson's Law** | Work expands to fill the time available, so shorten it. |
| **Eisenhower Matrix** | Sort tasks by urgent vs important: do, schedule, delegate, drop. |
| **Sprint planning** | Break the project into short cycles with clear goals. |
| **Daily stand-ups** | 15-minute check-ins: done, doing, blocked. |
| **Pomodoro** | Focused 25-minute work intervals with short breaks. |

### The Pomodoro Technique (Francesco Cirillo, late 1980s)

```
[25 work][5 break][25 work][5 break][25 work][5 break][25 work][15–30 long break]
```

1. Choose one task.
2. Set a timer for 25 minutes.
3. Work with no distractions.
4. Take a 5-minute break.
5. After 4 pomodoros, take a longer break.

### Sample 2-hour Pomodoro ideation workshop (team of 5)

| Block | Activity |
|---|---|
| P1 · 25 min | Review problem and write HMW questions |
| Break · 5 min | |
| P2 · 25 min | Brainwriting 6-3-5 + Crazy 8s |
| Break · 5 min | |
| P3 · 25 min | Cluster ideas; dot-vote the top 10 |
| Break · 5 min | |
| P4 · 25 min | Impact–feasibility matrix + weighted scoring |
| 15 min | Wrap up: pick 2 ideas to prototype |

## 🔑 Key Takeaways

- **Diverge first:** generate many ideas with no judgement.
- **Then converge:** cluster, evaluate and select.
- **Prioritise objectively:** matrices and scoring beat opinions.
- **Manage time:** timebox and use pomodoros to keep momentum.
