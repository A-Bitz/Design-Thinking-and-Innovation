## 🧭 The Design Thinking Process

```
 ┌───────────┐   ┌─────────┐   ┌─────────┐   ┌───────────┐   ┌────────┐
 │ EMPATHIZE │ → │ DEFINE  │ → │ IDEATE  │ → │ PROTOTYPE │ → │  TEST  │
 └───────────┘   └─────────┘   └─────────┘   └───────────┘   └────────┘
     Unit 2        Unit 2        Unit 3          Unit 4        Unit 4
```

Unit 1 introduces the process, and Unit 5 shows how organisations implement and scale it.

## 🙋 How to Use This E-Content

Each unit includes:

- 🎯 learning outcomes
- simple explanations with tables and diagrams
- real-world and campus examples
- 📝 practice questions (short and long answer)
- 🛠️ an assignment task with an evaluation rubric
- 📚 references for further reading

**Suggested approach:** read the unit before class, try the activity with your team, and use the practice questions to revise for exams.
